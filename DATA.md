# Data

GoSkills reuses the public data assets released with [Graph of Skills](https://github.com/davidliuk/graph-of-skills). Evaluation data is not committed to this repository; `scripts/download_data.sh` materializes the required files under gitignored directories.

## Assets

| Asset | Source | Destination |
|-------|--------|-------------|
| Skill libraries (`skills_200`, `skills_500`, `skills_1000`, `skills_2000`) | [DLPenn/graph-of-skills-data](https://huggingface.co/datasets/DLPenn/graph-of-skills-data) | `data/skillsets/` |
| SkillsBench task definitions | [benchflow-ai/skillsbench](https://github.com/benchflow-ai/skillsbench) | `evaluation/skillsbench/tasks/` |
| Optional GoS source bundles | Generated by upstream GoS benchmark scripts | `evaluation/skillsbench/generated_*/shared/graphskills_bundle.json` |

## Download

Download all public assets:

```bash
./scripts/download_data.sh --all
```

Download only part of the data:

```bash
./scripts/download_data.sh --skillsets
./scripts/download_data.sh --tasks
```

If the HuggingFace dataset is gated or mirrored:

```bash
HF_TOKEN=<hf-token> ./scripts/download_data.sh --skillsets
GOS_HF_REPO=your-org/your-dataset ./scripts/download_data.sh --skillsets
```

## SkillsBench Bundle Flow

GoSkills can consume an existing GoS source bundle when available:

```bash
export GRAPH_OF_SKILLS_ROOT=/path/to/graph-of-skills
python evaluation/skillsbench/gen_benchmark.py \
  --graph-of-skills-root "$GRAPH_OF_SKILLS_ROOT" \
  --skillset-name skills_1000 \
  --source-bundle "$GRAPH_OF_SKILLS_ROOT/evaluation/skillsbench/generated_table1_skills1000/shared/graphskills_bundle.json" \
  --output-root evaluation/skillsbench/generated_goskills
```

If `--source-bundle` is omitted, the generator falls back to building a bundle from the downloaded `SKILL.md` library through the upstream GoS benchmark builder.

## Expected Layout

```text
data/
└── skillsets/
    ├── skills_200/
    ├── skills_500/
    ├── skills_1000/
    └── skills_2000/

evaluation/skillsbench/
├── tasks/
└── generated_goskills/
    ├── shared/goskills_bundle.json
    └── tasks_goskills/
```
