# GoSkills

GoSkills builds reusable groups from a directed skill graph and retrieves a
bounded, source-backed execution contract for each query. The build/query path
uses Python's standard library and requires no model or embedding API.

## Pipeline

1. **Directed graph.** Skills are connected by typed relations. Prerequisite
   edges point from prerequisite to consumer; workflow edges point from earlier
   to later steps. Alternative and semantic relations are symmetric.
   Incompatibility suppresses positive relations for the same pair.
2. **Reusable groups.** Query-independent groups preserve lead and support
   roles, with at most three skills per group. Facet matching uses an inverted
   prefix join followed by exact Jaccard checks.
3. **Lexical seeds.** Binary TF–IDF cosine selects initial skills with normalized
   query/document lengths and deterministic tie-breaking.
4. **Bounded selection.** Group expansion balances relevance, requirement
   coverage, anchors, checks, connectivity, redundancy, incompatibility, and
   context cost while retaining eligible leads and prerequisites.
5. **Source-backed presentation.** Complete source sections are extracted with
   their ancestor scope and statically detected Python example prerequisites.
   Skill examples are never executed. Procedures that cannot fit use a
   disclosed source prefix rather than generated replacement instructions.
6. **Coverage debt.** Coverage is credited only from text shown to the agent.
   Uncovered explicit requirements remain in `DEBT`.

Contracts contain `START`, `SUPPORT`, `CHECK`, `AVOID`, `SKILLS`, and `DEBT`,
in that order. Query bundles include the selected groups, source spans, rendered
context, and selection trace.

## Usage

Prepare a skill library and export its graph following [DATA.md](../DATA.md).
Then run from the repository root:

```bash
python -m goskills build \
  --graph data/external/native-graph.json \
  --output /tmp/goskills-pool.json

python -m goskills query \
  --pool /tmp/goskills-pool.json \
  --query "Parse STL and output JSON" \
  --output-json /tmp/goskills-query.json --json

python -m goskills validate-bundle /tmp/goskills-query.json
```

Use fresh output paths; writes refuse to replace existing records. Reuse an
existing compatible group pool by skipping the build command.

## Configuration

| Parameter | Default |
|---|---:|
| Presented skills (`top_n`) | 4 |
| Lexical seeds (`seed_top_k`) | 4 |
| Skill body cap | 1,800 characters |
| Rendered-context cap | 9,000 characters |
| Members per group | 3 |
| Selected groups | 3 |
| Backfill cap | 2 |
| Neighbor limit | 2 |
| Group affinity threshold | 0.35 |

These are character limits, including paths and the rendered contract, rather
than tokenizer budgets. Feature weights and supported bounds are defined in
[config.py](config.py). Supply configuration overrides as JSON with
`goskills build --config path/to/config.json`. Unknown keys, non-finite values,
and unsupported bounds are rejected.

## File formats

- **Graph:** `schema_version: 1`, `kind: goskills_graph`, a nonempty `skills`
  list, and optional `edges`. Skills have unique `id`, `name`, `body`, and
  safe library-relative `source_path` fields. Optional descriptions and metadata
  preserve additional source information. Edge types are `dep`, `workflow`,
  `semantic`, `alternative`, `artifact`, `visible-check`, `fallback`, and
  `incompat`.
- **Pool:** generated by `goskills build`; contains the skills, groups, typed
  group relations, configuration, and integrity metadata. Rebuild a pool when
  changing its graph or construction code rather than editing the JSON.
- **Bundle:** generated by `goskills query`; contains the query, selection
  trace, presented skill text, rendered contract, and remaining coverage debt.
  `validate-bundle` checks its payloads, anchor, budgets, and debt against the
  rendered context.

## Import a Graph of Skills workspace

The `export-native` adapter accepts the directed Graph of Skills workspace
format from commit `203f60a2c689da055ce1ac351eb3cb9912a3bca7`. It requires that
clean checkout, its installed dependencies, the source skill library, and the
workspace's construction report.

```bash
export GOSKILLS_OFFICIAL_ROOT="$PWD/data/external/graph-of-skills"
.venv-retrieval/bin/python -m goskills export-native \
  --workspace data/external/workspace \
  --skills-root data/external/skills_2000 \
  --output data/external/native-graph.json
```

Export uses the upstream loader on a scratch copy, checks graph direction,
source text, vector dimensions, and indexing evidence, and makes no provider
calls. Use the upstream version and input layout documented in [DATA.md](../DATA.md).
